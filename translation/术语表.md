# 平均场博弈数值方法术语表

| English | 中文译法 | 说明 |
|---|---|---|
| mean field game, MFG | 平均场博弈 | 非合作主体的均衡问题 |
| mean field control, MFC | 平均场控制 | 合作主体或中央规划者的社会最优问题 |
| mean field type control | 平均场型控制 | 与 MFC 同类，但在题名等处保留原词形差异 |
| representative agent | 代表性主体 | 不译为“典型玩家”时用于经济学语境 |
| Nash equilibrium | 纳什均衡 | 有限主体近似时注意写作“近似纳什均衡” |
| value function | 值函数 | 不与伴随状态混同 |
| adjoint state | 伴随状态 | 变分或最大值原理中的对偶变量 |
| Hamiltonian | 哈密顿量 | HJB 语境下的 Hamiltonian |
| Hamilton--Jacobi--Bellman equation | Hamilton--Jacobi--Bellman 方程 | 简称 HJB 方程 |
| Fokker--Planck/Kolmogorov equation | Fokker--Planck/Kolmogorov 方程 | 描述状态分布的前向方程 |
| master equation | 主方程 | 定义在状态和概率测度空间上的方程 |
| McKean--Vlasov dynamics | McKean--Vlasov 动力学 | 系数依赖状态分布的随机动力学 |
| fixed-point iteration | 不动点迭代 | Picard iteration 保留为 Picard 迭代 |
| fictitious play | 虚拟博弈 | 不译为“虚拟游戏” |
| policy iteration | 策略迭代 | 强化学习和 HJB 数值法均可使用 |
| finite-difference scheme | 有限差分格式 | scheme 依语境译为格式或方案 |
| semi-Lagrangian scheme | 半拉格朗日格式 | 不写“半 Lagrange” |
| alternating direction method of multipliers | 交替方向乘子法 | 简称 ADMM |
| primal--dual method | 原始--对偶方法 | primal 不译为“初级” |
| monotone operator | 单调算子 | 与 Lasry--Lions 单调性区分 |
| price of anarchy | 无政府价格 | 社会最优成本与非合作均衡成本之比 |
| running cost | 运行成本 | 连续时间目标中的流量成本 |
| terminal cost | 终端成本 | 时间范围终点的成本 |
| drift | 漂移项 | 随机微分方程的确定性趋势项 |
| volatility | 波动率 | 扩散项尺度 |
| feedback control | 反馈控制 | 依赖当前状态的控制律 |
| density flow | 密度流 | 随时间变化的总体分布密度 |
| forward--backward system | 前向--后向系统 | 通常由分布前向方程和值函数后向方程耦合 |
